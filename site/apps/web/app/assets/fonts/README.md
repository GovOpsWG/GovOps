# Fonts

Self-hosted so the Content-Security-Policy can keep `font-src` at `'self'`. These are the latin
subsets Google Fonts serves; nothing else is bundled.

| File                                                 | Family                                          | Licence                   |
| ---------------------------------------------------- | ----------------------------------------------- | ------------------------- |
| `inter-latin-variable.woff2`                         | [Inter](https://github.com/rsms/inter)          | SIL Open Font License 1.1 |
| `poppins-600-latin.woff2`, `poppins-700-latin.woff2` | [Poppins](https://github.com/itfoundry/Poppins) | SIL Open Font License 1.1 |

The OFL permits redistribution of the font files, including bundled with software, provided the
licence travels with them. Full text: <https://openfontlicense.org>.

Note that the repository's CC0 dedication covers the working group's own documents, not these
fonts — they remain under the OFL.
