# Metric Definition Template — Draft

> Starter draft for review. The fields below will be refined through discussion.

| Field | Content to develop |
| --- | --- |
| Name and status | Name, owner, version, development stage and discussion link. |
| Purpose and benefit | The question answered, the decision supported and the expected organizational benefit, including enablement, risk or compliance where relevant. |
| Calculation | Definition, unit, formula, scope and reporting period. Explain exclusions and unknown values. |
| Evidence and context | Required records and fields, capability context where relevant, and any external inputs or estimates. |
| Interpretation | Meaning, limitations, possible action, and any thresholds with their applicable context and rationale. |
| Example | A small, reproducible calculation from stated inputs. Label illustrative data. |

See the [draft development process](acceptance_process_and_criteria.md) or return to the [draft metrics overview](../README_draft.md).
