# Illustrative Use Cases

Proposed examples of GovOps applied to concrete scenarios — three sector-specific deep dives and one
set of shorter, cross-cutting scenarios.

- [`agentic-workloads.md`](./agentic-workloads.md) — a natural-language interface deploying to a
  Kubernetes cluster through an MCP server, spanning multiple trust domains.
- [`financial-sector.md`](./financial-sector.md) — an automated trading agent executing high-value
  transactions, and how GovOps provides real-time oversight beyond after-the-fact audit logs.
- [`healthcare-sector.md`](./healthcare-sector.md) — an AI diagnostic tool accessing PHI across
  multiple record systems, and the granular, HIPAA-relevant audit trail GovOps enables.
- [`governance-scenarios.md`](./governance-scenarios.md) — six shorter, cross-sector scenarios
  (agent capability drift, credential revocation during execution, compliance audit preparation,
  cross-functional incident review, third-party trust review, and continuous governance metrics) in
  Situation / Need / How / Outcome form.

See [`../govops-thesis/README.md`](../govops-thesis/README.md) for the underlying model these use
cases apply, and [`../stakeholder-goals/README.md`](../stakeholder-goals/README.md) for what each
business function gets out of it.
