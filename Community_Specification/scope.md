# Scope

This document specifies a vendor-neutral framework for the continuous governance of authorization capabilities across applications, APIs, services, infrastructure, workloads, endpoints, and AI agents.

It:

* defines a machine-readable model for inventorying and classifying authorization capabilities as actions on resources;
* defines metrics for measuring changes in authorization risk, policy enforcement, accountability, and observability; and
* establishes a reference architecture connecting capability governance with distributed authorization, execution, evidence collection, detection, and response.

This document is applicable to organizations using centralized or distributed authorization infrastructures and is independent of the technologies used to make or enforce authorization decisions.

This document does not specify a policy language, policy decision point, authorization graph, identity provider, enforcement protocol, telemetry implementation, dashboard, maturity model, or formal verification method. It does not define how identities receive, retain, or certify entitlements.
